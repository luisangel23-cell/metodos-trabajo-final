Capítulo 3 Pruebas de hipótesis paramétricas y no paramétricas

Una vez finalizado el análisis exploratorio de los datos, se plantea y resuelve un conjunto de 11 preguntas mediante pruebas de hipótesis formales con un nivel de significancia \(\alpha = 0.05\) (confianza del 95 %), con el objetivo de verificar estadísticamente tanto la relación de cada una de las 5 variables predictoras con Performance Index (Preguntas 1 a 5) como la independencia entre los 6 pares de variables numéricas predictoras (Preguntas 6 a 11). Todas las pruebas se calculan con los 10,000 registros.

En las pruebas de correlación de Spearman se calcula además un intervalo de confianza del 95 % para el coeficiente \(\rho\) mediante la transformación de Fisher con el error estándar de Bonett y Wright, donde \(r_s\) es el coeficiente muestral y \(n\) el número de observaciones:

\[ z = \operatorname{arctanh}(r_s), \qquad EE = \sqrt{\frac{1 + r_s^2/2}{n - 3}}, \qquad IC_{95\%} = \tanh\left(z \pm z_{0.975}\,EE\right) \]

ICS <- list()

ic_spearman <- function(x, y, id, conf = 0.95) {
  n   <- length(x)
  rho <- cor(x, y, method = "spearman")
  ee  <- sqrt((1 + rho^2 / 2) / (n - 3))
  q   <- qnorm(1 - (1 - conf) / 2)
  lim <- tanh(atanh(rho) + c(-1, 1) * q * ee)
  S   <- (n^3 - n) * (1 - rho) / 6
  t   <- rho * sqrt((n - 2) / (1 - rho^2))
  p   <- 2 * pt(-abs(t), df = n - 2)
  ICS[[id]] <<- c(rho = rho, S = S, p = p, inferior = lim[1], superior = lim[2])
  data.frame(rho = rho, inferior = lim[1], superior = lim[2])
}

Pregunta 1: ¿Existe una diferencia significativa en el Performance Index entre estudiantes que realizan actividades extracurriculares y quienes no las realizan?

Inicialmente se plantea la comparación en términos de medias poblacionales (\(\mu_1\) para “No” y \(\mu_2\) para “Yes”):

\[ \begin{aligned} H_0 &: \mu_1 = \mu_2 \quad \text{(no hay diferencia entre los grupos)} \\ H_1 &: \mu_1 \neq \mu_2 \quad \text{(existe una diferencia entre los grupos)} \end{aligned} \]

Se separan los valores de Performance Index según Extracurricular Activities y se evalúa la normalidad en cada grupo mediante la prueba de Lilliefors.

sin_extra <- df %>% filter(Extracurricular_Activities == "No") %>% pull(Performance_Index)
con_extra <- df %>% filter(Extracurricular_Activities == "Yes") %>% pull(Performance_Index)

lil_no  <- lillie.test(sin_extra)
lil_yes <- lillie.test(con_extra)

Prueba Datos D p valor
Lilliefors (Kolmogorov-Smirnov) normality test con_extra 0.04922 < 0.001

Con una confianza del 95%, la prueba de Lilliefors muestra que las distribuciones de Performance Index para los estudiantes sin actividades extracurriculares (\(D = 0.04522\), p valor \(< 0.001\)) y con actividades extracurriculares (\(D = 0.04922\), p valor \(< 0.001\)) se desvían de la normalidad debido a su forma platicúrtica, por lo que no se emplea la prueba t paramétrica. Se replantea la hipótesis en términos de medianas (\(\eta_1\) y \(\eta_2\)):

\[\begin{aligned} H_0 &: \eta_1 = \eta_2 \\ H_1 &: \eta_1 \neq \eta_2 \end{aligned}\]

concl_sp <- function(p, rho) {
  ifelse(p >= 0.05, "No significativo",
         ifelse(abs(rho) < 0.1, "Significativo, sin relevancia",
                ifelse(abs(rho) < 0.3, "Significativo, débil",
                       ifelse(abs(rho) < 0.7, "Significativo, moderada",
                              "Significativo, fuerte"))))
}

filas_sp <- do.call(rbind, lapply(names(ICS), function(i) {
  v <- ICS[[i]]
  rho <- as.numeric(v["rho"])
  p   <- as.numeric(v["p"])
  etiqueta_var <- sub(" - Performance Index$", "", i)
  data.frame(
    Variable = etiqueta_var,
    Prueba = "Spearman",
    p_valor = ifelse(p < 0.001, "< 0.001", sprintf("%.4f", p)),
    Efecto = sprintf("$\\rho = %.4f$", rho),
    IC = sprintf("$(%.4f, %.4f)$", as.numeric(v["inferior"]), as.numeric(v["superior"])),
    Conclusion = concl_sp(p, rho),
    stringsAsFactors = FALSE
  )
}))

Los resultados muestran un panorama bien diferenciado:

Predictores con relevancia práctica individual: Previous Scores presenta una asociación positiva muy fuerte con Performance Index (\(\rho = 0.9207\), p valor \(< 0.001\)), y Hours Studied muestra una asociación positiva moderada (\(\rho = 0.3524\), p valor \(< 0.001\)). Ambas cumplen tanto significancia estadística como relevancia práctica.

redictores estadísticamente significativos pero débiles de forma aislada: Sleep Hours (\(\rho = 0.0451\)), Sample Question Papers Practiced (\(\rho = 0.0405\)) y Extracurricular Activities (\(r = 0.0219\)) resultan estadísticamente significativos con \(\alpha = 0.05\), pero su efecto marginal individual es pequeño cuando no se controla por la gran variabilidad introducida por Previous Scores y Hours Studied.

Independencia entre predictores: De los 6 pares de predictores numéricos evaluados, 0 resultaron estadísticamente significativos y el mayor coeficiente absoluto fue apenas \(|\rho| = 0.0173\), confirmando que los regresores no presentan redundancia ni multicolinealidad entre sí.
